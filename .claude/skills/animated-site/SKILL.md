# Генератор анимационных сайтов

## Режим 1. Разбор новых примеров

Когда в `references/` появились новые файлы:

1. Промты (PDF / текст): прочитать целиком, выписать стек, приёмы анимации, тайминги,
   палитру, шрифты, структуру блоков.
2. Видео: вытащить кадры, например
   `ffmpeg -i in.mov -vf "fps=1,scale=480:-1,tile=6x1" -frames:v 1 out.jpg`,
   и описать, что происходит при скролле.
3. Добавить в `patterns.md` только **обобщённые приёмы** (что делает и почему работает), а не чужой код.
4. Записать пример в таблицу «Разобранные работы» в `patterns.md`.

## Режим 2. Новый сайт

1. **Бриф.** Ниша, название, что продаём, главное действие (заказать / записаться / купить).
   Если чего-то нет, придумать и показать пользователю.
   Уточнить: для какой страны сайт, есть ли форма и куда уходят заявки (CRM, Telegram, почта).
2. **Концепт (3 варианта на выбор).** Для каждого: одна «сцена»-метафора, приём из `patterns.md`,
   палитра (тёмная база + 1 акцент), пара шрифтов, заголовок из 2–4 слов.
   Комбинации должны быть **новыми**, а не повторять разобранную работу.
3. **Медиа.** Сгенерировать в Higgsfield (generate_video / generate_image):
   - видео-сцена: два клипа по ~10 с, кадр конца первого = кадр начала второго (стык);
   - либо «разбор на слои»: отдельные PNG без фона для каждого слоя предмета.
4. **Код.** Vite + React + TypeScript + Tailwind v4 + `motion`. Скролл управляет таймлайном
   (useScroll → прогресс 0..1 → фазы). Компоновка на фиксированном холсте, масштаб по ширине окна.
   Отдельно проверить мобильную версию.
5. **Проверка.** `npm run build` без ошибок, скриншоты десктоп + телефон (Playwright).
   Если на сайте есть форма или сайт для РФ — пройти чек-лист `knowledge/152-fz.md` (152-ФЗ и русский язык по 168-ФЗ).
6. **Деплой** и живая ссылка.
7. **Контент.** Сценарий Reels 5–8 с: ноутбук + телефон, рука скроллит, ключевые моменты анимации.
   Плюс подпись к посту и хук на первые 2 секунды.

## Правила

- Работы из `references/` чужие. Нельзя копировать дословно ни код, ни тексты, ни медиа.
- Медиа хранить в проекте сайта и не подключать по чужим ссылкам.
- Тексты на сайте пишем на языке клиента.
