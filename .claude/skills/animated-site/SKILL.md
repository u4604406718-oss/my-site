# Генератор анимационных сайтов

## Режим 1. Разбор новых примеров

Когда в `references/` появились новые файлы:

1. Промты (PDF / текст): прочитать целиком, выписать стек, приёмы анимации, тайминги,
   палитру, шрифты, структуру блоков.
2. Видео: вытащить кадры, например
   `ffmpeg -i in.mov -vf "fps=1,scale=480:-1,tile=6x1" -frames:v 1 out.jpg`,
   и описать, что происходит при скролле.
3. Добавить в `patterns.md` только **обобщённые приёмы** (что делает и почему работает), а не чужой код.
4. Записать пример в таблицу «Разобранные работы» в `patterns.md`.

## Режим 2. Новый сайт

1. **Бриф.** Ниша, название, что продаём, главное действие (заказать / записаться / купить).
   Если чего-то нет, придумать и показать пользователю.
   Уточнить: для какой страны сайт, есть ли форма и куда уходят заявки (CRM, Telegram, почта).
   Зафиксировать **голос бренда** (кто говорит, тон, миф в одном предложении) и **реальные цифры** клиента —
   по разделу 1 и 4 `knowledge/copy.md`.
2. **Концепт (3 варианта на выбор).** Для каждого: одна «сцена»-метафора, приём из `patterns.md`,
   палитра (тёмная база + 1 акцент), пара шрифтов **с кириллицей** (раздел 9 `copy.md`), заголовок героя 2–6 слов
   по одной из формул раздела 2 `copy.md`.
   Комбинации должны быть **новыми**, а не повторять разобранную работу.
   Визуал сверять с `knowledge/visual.md`.
3. **Медиа.** Сгенерировать в Higgsfield (generate_video / generate_image):
   - видео-сцена: два клипа по ~10 с, кадр конца первого = кадр начала второго (стык);
   - либо «разбор на слои»: отдельные PNG без фона для каждого слоя предмета;
   - фото товаров каталога — по шаблону `references/prompts/product-photo-template.md`, всю серию в одной сессии;
   - ролик из кадров-ключей — по образцу `references/prompts/pizza-higgsfield-video.md`.
4. **Тексты.** До кода написать все тексты сайта по каркасу раздела 7 `knowledge/copy.md` (герой → о продукте → цифры →
   процесс → ассортимент → для кого/отзывы → попробовать → контакт → подвал) и показать пользователю.
   Типографика — раздел 8 (ёлочки, тире, ё, неразрывные пробелы, `1 290 ₽`).
5. **Код.** Vite + React + TypeScript + Tailwind v4 + `motion`. Скролл управляет таймлайном
   (useScroll → прогресс 0..1 → фазы). Компоновка на фиксированном холсте, масштаб по ширине окна.
   Видео по скроллу — строго по разделу «Движок видео по скроллу» в `patterns.md` (сглаживание + проверка `!video.seeking`).
   Подробные разборы похожих работ — в `knowledge/prompts/`.
   Хореографию ставить по разделу «Как ставить хореографию» в `patterns.md`: сначала сценарий в миллисекундах, потом доли скролла.
   Для видео/3D сразу заложить «Уровни устройств» (телефон / планшет / компьютер) и `prefers-reduced-motion`.
   Отдельно проверить мобильную версию.
6. **Проверка.** `npm run build` без ошибок, скриншоты десктоп + телефон (Playwright), ширины 360 / 390 / 768 / 1280 / 1920.
   Пройти чек-лист текста (раздел 11 `knowledge/copy.md`).
   Если на сайте есть форма или сайт для РФ — пройти чек-лист `knowledge/152-fz.md` (152-ФЗ и русский язык по 168-ФЗ).
7. **Деплой** и живая ссылка.
8. **Контент.** Сценарий Reels 5–8 с: ноутбук + телефон, рука скроллит, ключевые моменты анимации.
   Плюс подпись к посту и хук на первые 2 секунды.

## Правила

- Работы из `references/` чужие. Нельзя копировать дословно ни код, ни тексты, ни медиа.
- Медиа хранить в проекте сайта и не подключать по чужим ссылкам.
- Тексты на сайте пишем на языке клиента. Русские тексты — строго по `knowledge/copy.md`.
- Не использовать реальные бренды и людей без согласия: концепты для известных брендов подписывать как «концепт» и не продавать.
