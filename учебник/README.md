# Учебник: анимационные сайты с ИИ

Для Ирины. Простыми словами, без программирования. Каждый урок — 5–10 минут чтения и маленькое задание.
Подробности для агента лежат в `knowledge/`, а здесь — то, что нужно понимать **тебе**, чтобы ставить задачи,
оценивать результат и рассказывать об этом в Instagram.

## Как учиться

1. Читай по одному уроку в день, по порядку.
2. Делай задание в конце урока — оно короткое.
3. Непонятное слово — смотри в [словарике](02-словарик.md) или спроси Claude: «объясни простыми словами, что такое …».
4. После урока 5 делаем **первый учебный сайт вместе** — это лучшее закрепление.
