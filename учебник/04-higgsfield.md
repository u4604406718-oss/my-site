# Урок 4. Медиа в Higgsfield: фото, видео, кадры

Для анимационного сайта медиа — это **80% результата**. Плохое видео не спасёт никакой код. Higgsfield уже подключён к Claude,
поэтому можно просто попросить агента — но понимать, что просить, нужно тебе.

## Что бывает нужно сайту

| Что | Для чего | Как делать |
|---|---|---|
| **Фото товара на чистом фоне** | карточки каталога, меню | шаблон `references/prompts/product-photo-template.md` |
| **Видео-герой 8–10 с** | первый экран, видео по скроллу | картинка → видео в Higgsfield |
| **Два видео со стыком** | длинный «полёт» по скроллу | последний кадр первого = первый кадр второго |
| **Ролик по кадрам-ключам** | разбор на слои (пицца) | 3–4 картинки + промпт, как в `pizza-higgsfield-video.md` |
| **Персонаж, который осматривается** | эффект «следит за курсором» | схема `higgsfield-character-cursor.md` |
| **PNG без фона** | предметы, которые «падают», летают | удалить фон в Higgsfield |

## Пять правил хорошего промпта (из всех разобранных)

1. **Референс — закон.** «Use the uploaded image as the exact reference» — сохранить продукт, свет, фон, ракурс.
2. **Камера под контролем.** Либо «camera completely locked» (камера стоит), либо точно описать движение: «slowly orbits», «pushes in».
3. **Один непрерывный план.** «ONE continuous seamless shot, no cuts, no fades».
4. **Движение описано физикой:** не «появляется», а «вращается, поднимается, разлетается на слои, падает в коробку».
5. **Запреты в конце:** «Do NOT add objects, text, people. Do NOT redesign the product».
Бонус для кадров по скроллу: **«first and last frames must be identical»** — тогда видео можно крутить по кругу без скачка.

## Фото серии товаров
- Все фото каталога — **в одной сессии, одним промптом**: на сайте карточки стоят рядом, разный свет сразу видно.
- Выбилось одно — переделать **только его** тем же промптом.
- Не писать в промпте реальную марку («Rolex», «Додо») — получится чужой продукт, его нельзя публиковать.
- Для клиента — загрузить **фото его настоящего товара** как референс.

## Если что-то пошло не так
| Проблема | Что дописать |
|---|---|
| Товар мелкий | `tight crop, object fills 80 percent of frame height` |
| Фон серый/градиент | `pure flat solid #... background, no gradient` |
| Появились буквы/логотипы | `completely blank surfaces, no lettering` |
| Появилась рука | `product only, no hands` |
| Камера «гуляет» | `camera completely locked, no zoom, no pan` |
| Видео обрывается | `one continuous shot, no cuts, ends exactly on the final frame` |

## Как просить агента
Пиши Claude простыми словами, он сам соберёт промпт:
> «Сгенерируй в Higgsfield видео 10 секунд: стакан холодного латте на оранжевом фоне медленно поворачивается, камера стоит,
> первый и последний кадр одинаковые. Для сайта, видео по скроллу.»

## Задание
Возьми фото любой своей вещи (кружка, флакон, украшение) и попроси Claude сделать из неё фото «как в каталоге» по шаблону.
Сравни с оригиналом: что изменилось и почему так выглядит дороже.
