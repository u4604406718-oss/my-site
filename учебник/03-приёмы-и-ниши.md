# Урок 3. Какой приём для какой ниши

Агент знает 40 приёмов (список — в `.claude/skills/animated-site/patterns.md`). Тебе достаточно помнить **10 главных**
и для какого бизнеса они подходят. Остальные — «приправы».

## 10 главных приёмов

| Приём | Как выглядит | Подходит | Пример из папки |
|---|---|---|---|
| **Видео по скроллу** | крутишь — видео идёт вперёд/назад | почти всем | очки Orven, ювелирка, гидроцикл |
| **Разбор на слои** | продукт «взрывается» на части и собирается обратно | еда, косметика, гаджеты, одежда | пицца, куртка, часы |
| **Пролёт камеры** | камера летит в дом/зал/номер | недвижимость, отели, рестораны, салоны | вилла Tourist House |
| **Вертушка** | предмет крутишь мышкой | мебель, обувь, авто, украшения | дом Aerra |
| **Персонаж следит за курсором** | герой смотрит туда, куда ведёшь мышь | детские бренды, маскоты, школы | кот, лиса |
| **Карточка на паузе видео** | видео останавливается, выезжает товар с ценой | магазины | ювелирка |
| **Комната с метками** | на фото интерьера метки с ценами, наведи — предмет подсвечивается | мебель, интерьер, одежда, ресторан | Halden |
| **Сайт-фильм по кнопке** | один экран, кнопка «Начать», видео, потом карточки | эксперты, тренеры, мастера | йога-тренер |
| **Стопка блоков** | блоки наезжают друг на друга, как листы | любые «истории» | гонщик, парфюм |
| **Предмет за страницей** | один объект висит сзади и путешествует при прокрутке | онлайн-школы, IT, сервисы | планета Ascend |

## «Приправы», которые делают сайт дорогим

- **Красивая загрузка:** счётчик 0→100, шторки, чашка наполняется кофе, силуэт продукта заливается.
- **Текст появляется по словам** или «пишется пером».
- **Цифры катятся** как в счётчике: 1000+, 24/7, 30 мин.
- **Кнопка со стрелкой**, которая «уезжает» и появляется заново.
- **Шапка меняет цвет** под блок.
- **Зерно плёнки** и световые блики поверх видео.
- **Пульсирующая точка** «мы открыты».

## Подбор под нишу — шпаргалка

| Ниша | Главный приём | Приправы |
|---|---|---|
| Пиццерия, доставка | разбор на слои | загрузка-коробка, цифры, бегущая строка |
| Кофейня | видео по скроллу / зёрна вокруг стакана | загрузка-чашка, часы работы циферблатом |
| Салон красоты | пролёт камеры по салону | текст пером, кнопка «Записаться» |
| Недвижимость | пролёт / вертушка | цифры (м², минуты до центра), блок «для кого» |
| Ювелирка | видео по скроллу + карточка на паузе | тёмный фон, один светлый акцент |
| Одежда | разбор на слои / карточки наклоняются | бегущая строка, большие названия |
| Фитнес, тренер | сайт-фильм по кнопке | веер карточек-видео, «Привет, я …» |
| Детские товары | персонаж следит за курсором | яркий цвет, игривые тексты |
| Ресторан | комната с метками (блюда на столе) | меню, часы работы |

## Как выбрать самой
Спроси себя: **«Что в этом продукте самое вкусное, и как это показать движением?»**
Пицца — сыр тянется → разбор на слои. Дом — вид из окна → пролёт камеры. Кольцо — блеск камня → видео крупным планом.

## Задание
Возьми 3 бизнеса знакомых тебе людей (или из твоего района) и для каждого выбери главный приём и 2 приправы по шпаргалке.
