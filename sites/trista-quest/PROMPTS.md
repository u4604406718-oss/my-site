# Промпты для ChatGPT — «Час пик в Триста»

Всё делать **в том же чате, где получилась миниатюра** (`assets/scene-evening.webp`), чтобы стиль совпал.
Если чат потерян: загрузить картинку миниатюры и начать с промпта 0.
Каждую картинку просить **по одной**, PNG **с прозрачным фоном**.
Анимации (радость, ожидание, полёт) делаем кодом, поэтому каждому гостю хватает одной позы.

## 0. Закрепить стиль (если новый чат)
```
Это изометрическая миниатюра кофейни, которую я делаю для мини-игры. Дальше я попрошу отдельные
элементы для игры. Все элементы — строго в этом же стиле: та же 3D-миниатюра, тот же изометрический
ракурс сверху под углом, тот же тёплый янтарный свет, та же мягкая детализация. Каждый элемент — отдельно,
PNG с прозрачным фоном, без теней на полу, без текста. Подтверди и жди первый запрос.
```

## 1. Гости (6 картинок, по одной)
Общий текст, в конце подставить гостя:
```
Нарисуй одного гостя кофейни для этой миниатюры: человек стоит в полный рост, повёрнут
так же, как камера миниатюры (изометрия, 3/4 сверху), смотрит чуть вверх, дружелюбное лицо.
Пропорции чуть «игрушечные», как у фигурок в диораме, но не мультяшные. Стиль, свет и детализация —
точно как в миниатюре. PNG, прозрачный фон, без тени, без текста. Гость: [ГОСТЬ]
```
Гости (Улан-Удэ, ноябрь, люди разные, без карикатур):
1. молодая девушка-бурятка, длинные тёмные волосы, бежевое пальто, шарф
2. парень-бурят, студент, чёрный пуховик, рюкзак, наушники на шее
3. девушка славянской внешности, светлое каре, объёмный свитер, шоппер
4. мужчина лет 35 азиатской внешности, очки, тёмно-зелёная куртка, ноутбук под мышкой
5. женщина лет 50–55, бурятка, элегантное серое пальто, берет
6. спортивный парень славянской внешности, худи, бейсболка, спортивная сумка

## 2. Позиции меню (по одной; названия сверить с меню кофейни)
```
Нарисуй для этой миниатюры отдельный предмет: [ПОЗИЦИЯ]. Крупно, аппетитно, вид чуть сверху
под тем же углом, тот же тёплый свет и стиль, что у миниатюры. PNG, прозрачный фон, без тени,
без текста и логотипов.
```
1. Сырный раф в высоком прозрачном стакане, сливочная пенка
2. медовый макиато в стеклянном стакане, слои кофе и молока, капля мёда
3. латте «Солёная карамель», карамель на пенке
4. лимонный кекс с шариком мороженого на тарелочке
5. пончик в глазури
6. сэндвич в крафтовой упаковке
7. **красный перец чили** (для ошибки «Ой, остро!»)

## 3. Не обязательно
- Та же миниатюра **днём**: «Сделай эту же миниатюру днём: солнечный свет из окон, лампы выключены. Всё остальное без изменений».
- Логотип кофейни — взять у кофейни, не рисовать.

## Итого
6 гостей + 7 предметов = **13 картинок**. Higgsfield не нужен: «влёт» камеры, полёт предметов, пар, свет
и радость гостей делаем кодом. Higgsfield пригодится только для ролика в Reels.
