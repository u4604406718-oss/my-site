# Агент анимационных сайтов

Здесь живёт агент, который придумывает и собирает оригинальные сайты с анимацией по скроллу.

## Как устроено

```
.claude/skills/animated-site/   ← «мозг» агента: правила и рецепт сборки сайта
  SKILL.md                      ← инструкция, которую Claude Code читает сам
  patterns.md                   ← библиотека приёмов (растёт с каждым примером)
references/
  prompts/                      ← сюда кладём промты-примеры (PDF или текст)
  videos/                       ← сюда кладём видео-примеры (.mov / .mp4)
sites/                          ← сюда агент складывает готовые сайты
```

## Как пользоваться

1. Положи новые примеры в `references/prompts` и `references/videos`.
2. Открой Claude Code в этом репозитории и напиши: **«разбери новые примеры и обнови библиотеку приёмов»**.
3. Чтобы сделать сайт, напиши: **«сделай анимационный сайт для [ниша / бизнес]»**.

Примеры из `references/` нужны только для обучения. Агент делает новые, оригинальные сайты,
а не копирует чужие.
