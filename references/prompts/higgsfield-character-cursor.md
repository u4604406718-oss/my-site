# Higgsfield: персонаж, который «следит за курсором»

Источник: два скриншота из папки «анимация сайты» (кот на фиолетовом фоне, лиса в оранжевом худи),
плюс видео IMG_6926. Ниже пересказ схемы, а не дословная копия.

## Идея

Из одной картинки персонажа генерируем видео, где он осматривается по кругу и возвращается в исходную позу.
На сайте кадры этого видео выбираются по положению курсора (или по скроллу), и создаётся ощущение,
что персонаж смотрит туда, куда ведёшь мышью.

## Обязательные условия в промпте

- Загруженная картинка — точный референс: персонаж, пропорции, свет, фон, ракурс не меняются.
- Камера полностью зафиксирована: без зума, панорамы, поворота, кадрирования.
- Не добавлять новых объектов (курсор, точка, рука, частицы, тень).
- Двигается только нужное. Для кота: глаза → голова с небольшой задержкой → уши, шея, усы чуть-чуть.
  Для лисы: руки, голова, плечи, лёгкий наклон корпуса.
- Тело неподвижно: никакого дыхания, растяжения, подпрыгивания, искажения лица.
- Сценарий взгляда: влево → вниз-влево → вверх-влево → центр → вправо → вниз-вправо → вверх-вправо → исходная поза.
  Для лисы: жест «смотри туда!» влево, возврат, зеркально вправо, возврат.
- Небольшие паузы перед сменой направления, лёгкий «перелёт», плавные easing.
- **Первый и последний кадр идентичны**, чтобы видео можно было листать по кадрам без скачка.

## Применение на сайте

Видео → нарезка на кадры (ffmpeg) → canvas. Номер кадра считается по координате X курсора (или по прогрессу скролла).
Хорошо для: детских брендов, маскотов, игровых и креативных студий, любой ниши с персонажем.
