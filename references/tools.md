## Вердикт: что ставить и когда (27.10.2026)

**Уже есть в Claude Code:** Higgsfield MCP, скиллы frontend-design, impeccable, ui-ux-pro-max. Ставить заново не нужно.

**Сейчас (этап обучения):**
1. **grill-me.** Ложится в «Бриф» скилла animated-site и даёт точное ТЗ вместо догадок.
2. **content-skills.** Хуки и первый кадр для Reels, а Reels — главный канал за клиентами.
3. Больше ничего. Каждый лишний MCP/скилл съедает контекст и путает агента.

**Когда начнёте выкладывать (через 2–4 недели):**
4. **Instagram MCP.** Полезен для аналитики («какие ниши заходят»). Риски: это сторонний репозиторий одного автора
   с доступом к аккаунту. Перед установкой нужно прочитать код, а токен Meta хранить только локально.
   Публикацию оставить себе. Массовые авто-ответы в Direct не включать: за это могут заблокировать аккаунт.

**Когда пойдут заявки:**
5. **152-ФЗ.** Чек-лист для каждого клиентского сайта с формой: политика обработки ПДн, согласие с галочкой,
   cookie-баннер, хостинг данных в РФ. Это не MCP, а пункт в «Проверке» скилла.
6. **amoCRM MCP.** Только если клиентов станет много и ими нужно управлять. Тоже сторонний и тоже нужно смотреть код.

**По желанию / не нужно:**
- 21st.dev MCP: готовые компоненты, но они «стандартные». Для анимационных сайтов это минус. Нужен ключ.
- superpowers, find-skills: полезны для разработки вообще, для этой задачи не обязательны.
- Screenshot-to-Code: отдельное приложение. Claude Code и так умеет делать сайт по скриншоту.
  Копировать чужие сайты для клиентов нельзя.

## Что внутри каждой ссылки (изучено 27.10.2026)

### grill-me (mattpocock/skills)
- Команда `/grill-me`: агент допрашивает тебя по плану, пока не закрыта каждая развилка решения.
- Ставится целым пакетом: `claude plugin install mattpocock-skills@claude-plugins-official`, потом `/setup-matt-pocock-skills`.
- В пакете полезны ещё `teach` (объяснять тему, это для учебника Ирине) и `to-questionnaire` (превратить вопросы в анкету:
  **готовая анкета-бриф для клиента**).
- Где у нас: этап «Бриф». Ставить при первом своём сайте.

### content-skills (vyralcontent), 7 скиллов, бесплатно, MIT
- `viral-instagram-reels`: охват неподписчиков, Trial Reels для проверки на холодной аудитории, разбор провалившихся роликов.
- `viral-hooks`: первые 1–3 секунды в трёх слоях: картинка, голос, текст на экране.
- `viral-short-form-ideas`: рубрики, идеи из комментариев и у конкурентов.
- `viral-captions-and-ctas`: подписи, хэштеги, призывы к сохранению и пересылке.
- Ставить по одному: `npx skills add vyralcontent/content-skills --skill viral-instagram-reels` (и так же hooks, ideas, captions).
- Минус: написаны под англоязычные платформы. Примеры хуков нужно адаптировать под русский.
- Где у нас: этап «Instagram». Для наших роликов главный — `viral-hooks`, потому что у нас нет голоса, только картинка + текст на экране.

### Instagram MCP (adelaidasofia), 29 инструментов, MIT, 11 звёзд
- Плюс: **официальный** Instagram Graph API, а не логин с паролем. Бан за сам факт подключения не грозит.
- Нужно: профессиональный аккаунт (бизнес или автор), привязанный к странице Facebook, долгоживущий токен Meta.
- Умеет: статистику аккаунта и роликов, аудиторию, публикацию фото/видео/Reels/Stories/каруселей, комментарии,
  поиск по хэштегам, `business_discovery` (статистика чужих бизнес-аккаунтов: **разбор конкурентов**).
- Direct работает только после проверки приложения в Meta (долго). Пока её нет, эта часть выключена.
- Безопасность хорошая: запросы только на серверы Meta, токен вычищается из ответов, журнал каждого действия.
  Но в примере установки токен лежит открытым текстом в конфиге, его лучше хранить иначе.
- Проект маленький (один автор, 31 коммит). Перед установкой прочитать код и поставить конкретную версию.
- Вывод: ставим на этапе Instagram, сначала только на аналитику, публикацию — по подтверждению.

### amoCRM MCP (ivan000vovanov), 29 инструментов
- 0 звёзд, 2 коммита: совсем новый проект одного автора.
- Токен даёт полный доступ к CRM. Есть универсальный инструмент, который может **удалять** данные.
- Установка `npx github:...` тянет последнюю версию без фиксации.
- Вывод: только на этапе клиентов, после чтения кода, с фиксированной версией и на тестовой CRM. Не на CRM клиента.

### superpowers (obra)
- Методология разработки: мозговой штурм → план → выполнение по задачам → тесты → ревью.
- Полезный кусок для нас — `brainstorming` (дизайн по частям до кода) и `verification-before-completion`.
- Минус: заточен под программистов (тесты, git-ветки), сильно меняет поведение агента.
- Вывод: не ставим. Нужное уже есть в нашем скилле (3 концепта, проверка).

### find-skills (vercel-labs)
- Ищет скиллы по запросу, ранжирует по установкам и репутации. `npx skills add https://github.com/vercel-labs/skills --skill find-skills`.
- Вывод: не обязательно, искать скиллы могу и я.

### 21st.dev MCP
- Каталог 12 000+ React-компонентов. Поиск бесплатный, **получение кода и генерация платные**, нужен ключ.
- Вывод: не ставим. Готовые компоненты выглядят как у всех, а наш продукт — уникальная анимация.

### Screenshot-to-Code (abi)
- Скриншот, макет, Figma или **запись экрана** → код (HTML/React/Vue + Tailwind). Нужны ключи OpenAI/Anthropic/Gemini,
  запуск через Docker.
- Вывод: не ставим. Claude Code сам смотрит скриншоты и кадры видео (так разобраны все 19 роликов).
