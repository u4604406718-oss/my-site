## Вердикт: что ставить и когда (27.10.2026)

**Уже есть в Claude Code:** Higgsfield MCP, скиллы frontend-design, impeccable, ui-ux-pro-max. Ставить заново не нужно.

**Сейчас (этап обучения):**
1. **grill-me.** Ложится в «Бриф» скилла animated-site и даёт точное ТЗ вместо догадок.
2. **content-skills.** Хуки и первый кадр для Reels, а Reels — главный канал за клиентами.
3. Больше ничего. Каждый лишний MCP/скилл съедает контекст и путает агента.

**Когда начнёте выкладывать (через 2–4 недели):**
4. **Instagram MCP.** Полезен для аналитики («какие ниши заходят»). Риски: это сторонний репозиторий одного автора
   с доступом к аккаунту. Перед установкой нужно прочитать код, а токен Meta хранить только локально.
   Публикацию оставить себе. Массовые авто-ответы в Direct не включать: за это могут заблокировать аккаунт.

**Когда пойдут заявки:**
5. **152-ФЗ.** Чек-лист для каждого клиентского сайта с формой: политика обработки ПДн, согласие с галочкой,
   cookie-баннер, хостинг данных в РФ. Это не MCP, а пункт в «Проверке» скилла.
6. **amoCRM MCP.** Только если клиентов станет много и ими нужно управлять. Тоже сторонний и тоже нужно смотреть код.

**По желанию / не нужно:**
- 21st.dev MCP: готовые компоненты, но они «стандартные». Для анимационных сайтов это минус. Нужен ключ.
- superpowers, find-skills: полезны для разработки вообще, для этой задачи не обязательны.
- Screenshot-to-Code: отдельное приложение. Claude Code и так умеет делать сайт по скриншоту.
  Копировать чужие сайты для клиентов нельзя.
