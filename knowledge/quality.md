## 1. Концепт и вкус (проверяем до кода)

- [ ] ⛔ Есть **одна главная идея** сайта: сцена-метафора + один главный приём из `patterns.md`. Не «всё сразу».
- [ ] ⛔ Комбинация **своя**: не повторяет разобранную работу целиком (сверить с таблицей «Разобранные работы»).
- [ ] Главный приём подходит нише (таблица «Хорошо для» в `patterns.md`) и бюджету клиента:
      видео/кадры для малого бизнеса, 3D/шейдеры — только для tech/премиума.
- [ ] Палитра: база + **один** акцент. Акцент живёт в 2–3 местах (кнопка, выделенное слово, «живая» точка), а не везде.
- [ ] Максимум 2–3 шрифта, роли разведены (заголовок / текст / метки), **все с кириллицей**.
- [ ] Есть **один графический жест** на весь сайт (уголки-рамка, линия, полоса, перо), который повторяется в прелоадере, курсоре, кнопках.
- [ ] Ритм блоков: тёмный ↔ светлый, крупное ↔ мелкое. Нет двух одинаковых блоков подряд.
- [ ] ⛔ Нет реальных брендов, людей и логотипов без согласия (концепт для известного бренда — только с подписью «концепт» и не для продажи).

## 2. Первый экран

- [ ] ⛔ Продукт / герой крупно, считывается за 1 секунду без прокрутки.
- [ ] Заголовок 2–6 слов, одно акцентное слово (`copy.md`, раздел 2).
- [ ] Меню тонкое, не спорит с героем; главная кнопка видна сразу.
- [ ] Текст читается поверх видео/фото: своё затемнение под блоком текста или `mix-blend-mode: difference`, тень под текстом.
- [ ] Герой играет анимацию **после** прелоадера, а не за ним.

## 3. Прелоадер

- [ ] Прогресс **честный** (шрифты, кадры, модель), а не таймер. Минимум ~0.6–1.5 с, страховка 4–8 с.
- [ ] Прелоадер — часть бренда: силуэт/ёмкость продукта, рамка с товарами, название продукта на счётчике.
- [ ] Прокрутка заблокирована, пока шторка закрыта; страница открывается с самого верха.
- [ ] Уходит жестом (шторки расходятся, окно растёт, «выливается»), а не просто гаснет.
- [ ] `<noscript>` прячет прелоадер; при `reduced-motion` его нет.
- [ ] Под шторкой заранее прорисован первый кадр / скомпилирована 3D-сцена (первая прокрутка не дёргается).

## 4. Анимация и хореография

- [ ] ⛔ Сценарий записан как **раскадровка в миллисекундах** и переведён в доли скролла (`patterns.md`, «Как ставить хореографию»).
- [ ] Каскады: слова 0 / 75 / 150 мс, строки 200 / 275 / 350 мс, блоки ~80 мс. Текст героя ждёт окончания главной анимации.
- [ ] Всё на пружинах или expo-out, без линейных появлений; пружины без «резинового» перелёта для текста.
- [ ] Текстовые слои — «акты»: входят при входе в окно, выходят тем же движением в обратном порядке; блоки в режиме **forward**
      (при прокрутке вверх не мигают).
- [ ] Разные движения одного элемента — на **разных вложенных обёртках** (появление / наклон / параллакс / поворот).
- [ ] Размытие только у текста, у блоков — сдвиг + прозрачность.
- [ ] Видео/кадры доходят до последнего кадра на ~80% своей фазы, есть пауза «полюбоваться».
- [ ] Микро-анимации из библиотеки (`patterns.md`): цифры-барабан, рисующиеся линии, кнопка со стрелкой, ссылка-перекат.
- [ ] Ничего не анимируется «просто так»: у каждого движения есть смысл (показать продукт, направить взгляд, ответить на действие).

## 5. Видео и кадры

- [ ] ⛔ Видео по скроллу: сглаживание 0.08–0.09 + перемотка только при `!video.seeking`; iOS: `play()`+`pause()` на `loadedmetadata`.
- [ ] Короткие тяжёлые сцены (вращение, разбор на слои) — **кадры на canvas** со смешением соседних кадров.
- [ ] Загрузка кадров: каждый 6-й → остальные, пул ~12, ближайший кадр при пропуске, ошибка кадра не ломает загрузку.
- [ ] ~3vh прокрутки на кадр; частота кадров под движение (24 к/с быстро, 12 к/с медленно).
- [ ] Стык двух клипов: общий кадр или размытие + прозрачность — без видимого скачка.
- [ ] ⛔ Все медиа лежат **в проекте**, ни одной ссылки на чужие хранилища (getlayers, cloudfront, r2.dev, cloudinary).
- [ ] Фото товаров одной серии: один промпт, одна сессия, одинаковый свет (`references/prompts/product-photo-template.md`).
- [ ] Вес: герой-медиа на телефоне ≤ ~5–8 МБ; кадры для телефона меньше и мельче.

## 6. Телефон и разные экраны

- [ ] ⛔ Нет горизонтальной прокрутки на **360, 390, 768, 1280, 1920** px.
- [ ] Мобильная версия **перекомпонована**, а не уменьшена: продукт сверху, текст под ним, кнопка во всю ширину.
- [ ] Холст (фиксированная раскладка) — только на широком горизонтальном экране; планшет вертикально = как телефон.
- [ ] Мелкий текст ≥ 12 px; основной текст на телефоне ≥ 15–16 px; русские заголовки-капс не ломаются посреди слова.
- [ ] Зона нажатия ≥ 44 px (невидимый `::before`, если рисунок мельче).
- [ ] Эффекты наведения выключены на сенсорных экранах; у карточек действие («Заказать») видно всегда.
- [ ] Курсорные эффекты (наклон, рябь, решётка, след) заменены на статичную позу или автоматический проход.
- [ ] Телефон горизонтально (`max-height: 500px`) — герой не разваливается.

## 7. Скорость и техника

- [ ] ⛔ `npm run build` без ошибок и предупреждений типов.
- [ ] Один общий `requestAnimationFrame`-тикер; неподвижная страница = 0 кадров; секции вне экрана не рисуются.
- [ ] Уровни устройств: телефон / планшет / компьютер (частицы ×0.34, плотность пикселей ≤ 0.85–1.25, 30 к/с на телефоне, ~60 на компьютере).
- [ ] Тяжёлое (three.js, 3D, кадры следующих секций) грузится, когда до секции ~600–800 px.
- [ ] Огромный заголовок показывается только после `document.fonts.ready`.
- [ ] `overflow-x: clip` (не `hidden`), без `width: 100vw`; трансформации не на `sticky`-элементах.
- [ ] Lighthouse на телефоне: Performance ≥ 70, CLS ≈ 0 (элементы не прыгают при загрузке).

## 8. Тексты

- [ ] ⛔ Пройден чек-лист текста (`copy.md`, раздел 11): голос, формулы, цифры-правда, одна главная кнопка, типографика.
- [ ] ⛔ Для РФ: все надписи на русском (168-ФЗ), английские слова только с русским вариантом или как товарный знак.
- [ ] Тексты согласованы с пользователем **до** кода.

## 9. Доступность

- [ ] `prefers-reduced-motion`: всё показано в конечном состоянии (не «выключено», а «готово»), видео-скролл стоит на ключевом кадре.
- [ ] Разбитый на буквы/слова текст: анимированные куски `aria-hidden`, настоящий текст в скрытой копии.
- [ ] Один `<h1>`, у каждой секции `<h2>`; ссылка «Перейти к содержимому».
- [ ] Видимый фокус на всех кнопках и ссылках с клавиатуры.
- [ ] Альт-тексты у всех фото; декоративное — `aria-hidden`.
- [ ] Контраст текста к фону достаточный (особенно серый мелкий текст на тёмном и белый поверх видео).
