# «Sculpted by time» (ювелирка): подробный разбор

PDF «jewelry», 6 страниц. Видео IMG_8585. Приёмы: 1 (видео по скроллу), 10 (текст тает), + новый: **выезжающая карточка товара**.

## Суть
Страница высотой **650vh** на почти чёрном фоне. Прокрутка листает два видео (украшения крупным планом на модели).
Редакционный текст героя «тает» вверх с размытием. На паузах между видео **слева выезжает светлая карточка товара**
с кнопкой «в корзину», количеством и ценой. Это не просто красивая витрина: на пике анимации можно **купить**.

## Стек
React 19 + TypeScript + Vite 6 + Tailwind v4 + lucide-react (иконки) + motion. Всё в одном `App.tsx`.

## Сценарий прокрутки
| Прогресс | Что происходит |
|---|---|
| 0–40% | Видео 1 листается. Текст героя тает поэлементно (окна 0.00–0.31) |
| 40–50% | Видео 1 стоит на последнем кадре, **выезжает карточка 1** (серьги) |
| 48% | Видео 1 → видео 2 через затухание 700 мс |
| 50–90% | Видео 2 листается |
| 90–100% | **Выезжает карточка 2** (кольцо) |
Логика: видео играет → пауза → товар → видео → товар. Ритм «показали — предложили купить».

## Движок (отличия от Orven)
- **Двойное сглаживание.** Сам прогресс прокрутки догоняет цель с коэффициентом **0.05** («тяжёлое», киношное ощущение),
  а время видео догоняет свой прогресс с **0.08**.
- Перемотку не делаем, **пока браузер ещё ищет прошлый кадр** (`video.seeking`). Это убирает рывки без таймеров.
- Значения анимации хранятся в `useRef`, а не в состоянии React: иначе компонент перерисовывается 60 раз в секунду.
- Прослушивание скролла `passive`, плюс первый расчёт сразу и через 500 мс (когда видео подгрузились).

## «Тающий» текст (getStaggerStyle)
Для каждого элемента своё окно прогресса; внутри окна: прозрачность 1→0, сдвиг вверх до 75 px, размытие до 16 px.
Окна сдвинуты на 0.03: логотип 0.00–0.12, меню 0.03–0.15, подзаголовок 0.06–0.18, строки заголовка 0.09/0.12/0.15,
манифест 0.18/0.21, подпись товара 0.14–0.25, карточка 0.18–0.29, цена 0.20–0.31.
Получается, что интерфейс уходит **волной сверху вниз**, а не весь разом.

## Цвет
- Фон `#020202`, текст белый.
- **Один акцент `#FBFF8D`** (бледный лимонно-жёлтый): заголовок, полоса прогресса, наведения, точка на корзине.
- Карточка товара тёплая «бумага» `#FAF9F5`, текст `#121212`, серые `#8E8B84 / #73716C / #E5E5E2`.
- Отдельный запрет: «никакого фиолетового». Хорошая привычка: в ТЗ явно запрещать цвет, который ИИ любит добавлять сам.

## Типографика
- **Instrument Serif** (заголовки) + **Manrope** (интерфейс).
- Заголовок капсом в 3 строки, межстрочный **0.88** (строки почти касаются), размер `clamp(2.5rem, 5.6vw, 7.5rem)`.
  Отдельные слова **курсивом**: «*SCULPTED* / BY TIME. WORN / BY *YOU*». Первая строка сдвинута пробелами вправо.
- Мелкий текст 11–13 px с прозрачностью 50% — контраст с огромным заголовком.
- Метки капсом с разрядкой 0.15em.

## Детали, которые делают «дорого»
- Тонкая **полоса прогресса 2.5 px** акцентным цветом сверху.
- Три градиента-затемнения (сверху, снизу, слева), чтобы текст читался на любом кадре.
- Ссылки меню с подчёркиванием, которое «вырастает» при наведении.
- Пульсирующая точка на значке корзины.
- Кнопка корзины прокручивает сразу к последнему товару, кнопка «назад» в карточке возвращает в видео.
- Своя тёмная полоса прокрутки 6 px.
- Выезд карточки 1100 мс с той же кривой expo-out `cubic-bezier(0.16,1,0.3,1)`.

## Что берём в агента
1. **Приём «карточка на паузе видео»** (новый, №17 в patterns.md): видео останавливается, сбоку выезжает товар с ценой и кнопкой.
   Для любого магазина: украшения, косметика, одежда, еда (карточка блюда с кнопкой «Заказать»).
2. Двойное сглаживание 0.05 + 0.08 и проверка `video.seeking`.
3. Волна исчезновения интерфейса со сдвигом окон на 0.03.
4. В ТЗ явно запрещать «любимые» цвета ИИ.

## Слабые места оригинала
- Медиа по чужим ссылкам Cloudinary.
- Корзина «для вида»: нет оформления заказа. Для клиента нужна реальная ссылка (форма, мессенджер, маркетплейс).
- Нет описания мобильной версии, кроме ширины карточки. Для телефона продумать самим.
