# Ascend (SaaS с вращающейся Землёй): подробный разбор

PDF «Earth», 16 страниц. Видео IMG_5885. Приёмы: 13 (шейдерный фон), 10 (появление), + новый: **3D-объект за всей страницей, который «путешествует» по ключевым точкам**.

## Суть
Обычный по структуре лендинг (герой → 6 фич → «витрина» с дашбордом и цифрами → призыв + подвал),
но **за всей страницей висит одна 3D-планета**. При загрузке она «всплывает» снизу огромной, наполовину за краем экрана.
При прокрутке уменьшается, уходит влево, потом вправо, вращается и встаёт в центр к финальному призыву.
Весь контент — полупрозрачные «стеклянные» карточки поверх планеты.

**Главный вывод:** вау-эффект здесь даёт **один фон**, а сам сайт — стандартный шаблон SaaS. Это дешёвая формула:
«обычный хороший лендинг + один живой объект сзади».

## Стек
Один `index.html`, без сборки. **Three.js r0.143** (версия зафиксирована, потому что код шейдеров завязан на её внутренности),
GLTF + Draco (сжатая 3D-модель), постобработка (свечение bloom), **Lenis** для плавной прокрутки, шрифт Inter.

## Как планета «путешествует» (главный приём, его можно взять без шейдеров)
Ключевые точки по прогрессу прокрутки:
```
          p=0      p=0.32   p=0.64   p=1
X         0        −3.1     +3.2     0       (влево → вправо → центр)
Y        −4.5      0.55     0.45     0.15    (снизу огромная → поднимается)
масштаб   2.15     1.0      0.92     1.12
```
- Между точками — плавный переход smoothstep (`t·t·(3−2t)`).
- Прогресс сглажен: `curP += (цель − curP) × min(1, dt × 4.5)`; позиция догоняет с `dt × 3.2`.
  Объект «плывёт», а не прыгает за колесом мыши.
- На узких экранах боковой ход уменьшается: `× clamp(ширина/1200, 0.5, 1)`. Иначе планета уходит за край телефона.
- Вращение добавляется от прокрутки: `+ прогресс × 1.6π`, плюс медленное собственное вращение.
- **Вход один раз** после загрузки модели: подъём снизу за 1.9 с с кривой `1 − (1−t)³`.
- Отдельного прелоадера нет: «открытие» = текст проявляется по очереди (60 → 180 → 300 → 420 мс) + планета всплывает.

Эта схема «объект по ключевым точкам» подходит для **любого** фонового предмета: бутылка, кроссовок, кольцо, чашка.

## Что делает планету живой (из чего состоит сцена)
- Своя «кожа» шейдером: день/ночь, огни городов на ночной стороне, блики и течения на океане, светящийся контур.
- Мягкий голубой ореол сзади, три слоя облаков с разной скоростью, ~320 пылинок, 1400 мерцающих звёзд.
- 60 золотых «радар-пингов» **только на суше** (точки, от которых расходятся кольца).
- Финальный проход: свечение + «языки пламени» по углам экрана.
Это сложная часть (≈400 строк шейдеров). Для клиентов малого бизнеса избыточно; для tech/SaaS — сильный аргумент.

## Дизайн контента
- Палитра «глубокий космос»: фон `#04060f`, текст `#f3f6ff`, приглушённые `#9aa6c4 / #6b7796`, **мятный акцент `#5df0a8 → #2fd38a`**.
- «Стекло»: фон `rgba(12,18,38,.55)` + размытие 14–18 px + тонкая линия `rgba(150,175,230,.12)`, скругления 18 / 26 px.
- Заголовок: Inter 800, `clamp(34px, 5.2vw, 62px)`, межстрочный 1.04, трекинг −0.03em.
  Ключевое слово («*Harder*») — не курсив, а **градиент акцентного цвета внутри букв**.
- Тексту поверх 3D добавлена мягкая тень `0 2px 50px rgba(0,0,0,.55)`, а у героя — затемнение **только сверху**,
  чтобы меню и заголовок читались, а планета была видна.
- Надзаголовок (eyebrow) 12 px капсом, разрядка 0.18em, акцентным цветом: «Everything in orbit».
- Кнопки-«таблетки»: основная с градиентом и цветной тенью, вторая — прозрачная со стеклом. При наведении поднимаются на 2 px.
- Карточки фич: иконка в квадрате 46×46 с акцентным фоном 10%; при наведении поднимаются и в углу проявляется зелёный отсвет.
- Дашборд-«макет»: столбики растут снизу (по 90 мс друг за другом), полосы заполняются слева.
- Цифры: «3.4× / 92% / 11k+ / $2.1B» с градиентом от белого к акценту.
- Ряд логотипов «Trusted by…» под героем (социальное доказательство).

## Анимация появления (простая и универсальная)
- `IntersectionObserver` (порог 0.18, отступ −8% снизу) добавляет класс `.in` один раз.
- Скрыто: прозрачность 0, сдвиг вниз 26 px; появление 0.7 с, кривая `cubic-bezier(.22,.7,.2,1)`.
- Задержка через CSS-переменную `--rd` у каждого элемента: шаг 80–90 мс для карточек.
- **`prefers-reduced-motion`:** всё показывается сразу, Lenis и вход планеты отключены. Это пункт доступности, который надо делать всегда.

## Плавная прокрутка
`new Lenis({ duration: 1.15, smoothWheel: true, touchMultiplier: 1.5 })` + свой цикл `requestAnimationFrame`.
Холст с 3D `position: fixed`, `pointer-events: none`: он **никогда не перехватывает** мышь и прокрутку.

## Что берём в агента
1. **Приём №22 «Объект за страницей по ключевым точкам»**: X / Y / масштаб / поворот на 3–4 точках прогресса, smoothstep, двойное сглаживание.
   Работает и с 3D-моделью, и с вырезанным PNG/видео без фона.
2. Формула «стандартный лендинг + один живой фон» для tech/SaaS/онлайн-школ.
3. Универсальное появление по `IntersectionObserver` + `--rd`.
4. Всегда `prefers-reduced-motion`.
5. Тень под текстом и затемнение только там, где текст.

## Слабые места оригинала
- Все тексты и бренды выдуманы («Nimbus, Pluma…» в логотипах) — для клиента нужны реальные.
- Модель и текстуры по чужим ссылкам getlayers.ai.
- Тяжело для слабых телефонов: 3 прохода рендера + свечение + тысячи точек. Нужна облегчённая версия
  (меньше звёзд, без bloom, ограничить плотность пикселей).
- Все кнопки — заглушки, формы нет.
