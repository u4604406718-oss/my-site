# OYLA (кольца ручной работы): подробный разбор

PDF «ola», 9 страниц. **Поправка к прежнему разбору:** видео IMG_8784 (бренд «Orla», одежда на белом фоне) — это **не** этот сайт.
Видео к OYLA в папке нет. В таблице patterns.md исправлено.

Приёмы: 1 (видео по скроллу), 4 (параллакс), + новые: **горизонтальная лента товаров, раскрывающая видео**,
**подвал, который «открывается» из-под страницы**.

## Суть
Белый минималистичный магазин колец. Сверху **500vh** видео, которое листается скроллом, заголовок «MEASURED PURITY».
Потом секция закрепляется, и **товары едут горизонтально** (6 карточек по трети экрана).
Когда лента кончилась, из центра **раскрывается второе видео** во весь экран. Дальше два столбца:
слева закреплённый текст о бренде, справа прокручиваются 4 карточки с цифрами. В конце подвал «проявляется» из-под страницы.

## Стек
HTML с встроенными стилями и скриптом + **GSAP 3.12.5 + ScrollTrigger** + Vite + Express (сервер).
Express нужен только для одной хитрости: по ссылке «поделиться» из Higgsfield (`higgsfield.ai/s/...`)
сервер достаёт прямую ссылку на mp4. **Видео и картинки товаров сгенерированы в Higgsfield.**

## Самое важное техническое правило (автор выделяет его отдельно)
```
если (!video.seeking и разница > 0.01 с) → video.currentTime = нужное время
нужное время += (цель − нужное время) × 0.08   // каждый кадр
```
Без проверки `video.seeking` браузер получает поток запросов перемотки и видео **замирает, мигает чёрным, дёргается**.
Это подтверждается во всех трёх разобранных видео-промптах (Orven, ювелирка, OYLA): **правило №1 для любого видео по скроллу.**

## Сценарий
| Блок | Длина | Что происходит |
|---|---|---|
| Видео-герой | 500vh | видео листается; после 80% прогресса буквы заголовка по одной гаснут, размываются, уходят вверх; кнопка уходит по кривой `progress⁴` |
| Лента товаров | закреплена | 6 карточек по 33vw едут влево, `scrub: true` (жёстко привязано к скроллу) |
| Раскрытие видео | там же | обёртка растёт по ширине от 0% до 100% **из центра**, под ней листается второе видео |
| Цифры | 2 колонки | слева закреплённый текст (появление: прозрачность + 20 px вверх, шаг 0.15 с, 0.8 с, power2.out), справа 4 карточки |
| Подвал | — | фиксирован под страницей; страница «уезжает» и открывает его |

## Дизайн
- Белый фон, чёрный текст, **чёрные линии 1 px** между всеми блоками (как разлинованный каталог).
- **Единственный цвет — бордовый `#A3111E` только в шапке** (логотип, меню). Строже, чем «акцент везде».
- Шрифты: **Instrument Serif** (заголовки, цифры) + **Inter Tight** (всё остальное).
- Кнопка-«таблетка» с кружком «+» справа; при наведении цвета инвертируются. Своя кнопка = узнаваемость бренда.
- Меню в квадратных скобках: «[ BAG ]».
- Карточки-цифры: «100% / Handmade», «14–92g / Per piece», «Lifetime / Guarantee». Огромная цифра + слово + пояснение.

## Тексты
Сильный «голос» бренда короткими рублеными фразами: «Not decoration — declaration», «Edges are left where they fall».
Рассказ о процессе: кто делает, из чего, почему так. Для ручной работы это главный аргумент к цене.

## Технические приёмы, которые стоит запомнить
- Анимации запускать на `document.fonts.ready`, а не на полной загрузке страницы: видео грузятся долго, а сетка уже готова.
- При изменении ширины окна (с задержкой 200 мс) пересобирать все ScrollTrigger, иначе позиции съезжают.
- Подвал-«занавес»: подвал `position: fixed` внизу + пустой блок той же высоты в конце страницы.
- Адаптив: на телефоне колонки в одну, закрепление отключено, кнопки во всю ширину и не ниже 44 px (размер пальца).

## Что берём в агента
1. Правило `!video.seeking` — обязательное, вписать в SKILL.md.
2. **Приём №20 «Лента товаров → раскрытие видео»**: горизонтальная прокрутка каталога, в конце видео «из центра».
   Для магазинов с 5–10 ключевыми товарами.
3. **Приём №21 «Подвал-занавес».** Простой и всегда выглядит дорого.
4. Карточки «цифра + слово + пояснение» для блока преимуществ.

## Слабые места оригинала
- Express ради прокси к Higgsfield — лишний сервер. Правильнее скачать готовое видео и положить в проект.
- Подписка на рассылку через `alert()`: формы нет, данные никуда не уходят. Для клиента нужна настоящая форма + 152-ФЗ.
- Товары 5 и 6 используют те же картинки, что 1 и 2: демо, не реальный каталог.
