# Marlin (электро-гидроцикл): подробный разбор

PDF «Water», 29 страниц. Видео в папке нет. Приёмы: 1 (видео по скроллу), 3 (фиксированный холст), 4 (параллакс-лента), 5 (финал).
Этот промпт — **самый полезный для понимания метода**: в комментариях кода автор объясняет, откуда взялись все числа.

## Суть
Вся страница — одна сцена: гидроцикл несётся по воде на закате, снято сверху. Прокрутка двигает не страницу, а **таймлайн**.
Три группы контента (герой → «Born To Glide» с 4 карточками → «под водой») едут вверх **с разной скоростью**,
как плёнка с параллаксом. Под ними два 10-секундных видео, сшитые через общий кадр, так что поездка не прерывается.
После сцены — обычный подвал.

## Главное открытие: хореография делается как **ролик по времени**, а не по скроллу
Автор сначала собрал анимацию в Figma-прототипе: 19 переходов, всего **20 000 мс**.
Потом каждое время разделил на 20 000 и получил доли прокрутки:
```
at(мс) = мс / 20000          // 0..1 — где на скролле это происходит
слово «Redefine»  0–300 мс   → at(0)…at(300)
слово «Ocean»     75–375 мс  → сдвиг 75 мс
слово «Speed»     150–450 мс
строки текста     200 / 275 / 350 мс
переход 1         8000–14000 мс
переход 2         15500 мс → 0.90 (сжат, чтобы финал постоял перед подвалом)
```
**Вывод для агента:** сначала пишем сценарий «как видео» в миллисекундах (что за чем, сколько длится, с каким сдвигом),
потом переводим в доли скролла. Так получается «хореография», а не набор случайных появлений.
Автор прямо пишет: каскад 0 / 75 / 150 мс — это разница между «поставленной сценой» и «простым проявлением».

## Две функции на всё
- `span(p, [a, b])` — плавная (cubic ease-out) от 0 до 1 внутри окна. Для появлений.
- `ramp(p, [a, b])` — линейная. Для движений, которые должны идти **точно за скроллом** (сдвиги групп, затемнения).
- `lerp(a, b, t)` — промежуточное значение. Позиции групп заданы по 3–4 «ключевым кадрам» из прототипа.

## Фиксированный холст (подробности)
- Холст **1440×810** (16:9), всё внутри — абсолютные координаты макета.
- Масштаб **только по ширине**: `scale = ширина окна / 1440`. Не по минимуму (будут полосы) и не по максимуму (обрежет).
- Высота сцены `max(100vw × 810/1440, 100vh)`: на высоких экранах фон продолжается, а не обрывается.
- **Меню вне холста**, в обычном размере, иначе на телефоне его не прочитать. Ссылки меню прячутся меньше 640 px.
- Безопасное поле 96 px по бокам: часть холста может обрезаться, текст должен стоять внутри.
- «Хочешь поменять дизайн — меняй координаты на холсте, не оборачивай в сетку».

## Видео
- Генерация даёт максимум ~10 с, поэтому **2 клипа**: A (сверху → профиль на закате), B (профиль → под воду).
  Последний кадр A = первый кадр B (разница 4.2%). Переключение на середине скролла (`VIDEO_SEAM = 0.5`)
  через растворение в узком окне ±0.02.
- Движок проще, чем в других промптах: каждый кадр `время += (цель − время) × 0.26`, если разница > 0.012 с.
  Проверки `seeking` нет — для коротких лёгких клипов работает, но для надёжности берём наш общий движок из patterns.md.
- Чтобы видео показало первый кадр до прокрутки: на `loadedmetadata` поставить `currentTime = 0.01`.

## Читаемость текста на движущейся воде
- Каждый блок текста получает **своё затемнение**, а не надеется, что кадр окажется тёмным:
  слева-направо для героя, радиальное снизу для карточек, снизу-вверх для финала. Каждое проявляется в свою фазу.
- Шапка: градиент сверху + размытие 10 px, и **маска гасит размытие плавно** — нет «жёсткой линии» поверх видео.
- Подписи на карточках-картинках — на собственном тёмном градиенте внутри карточки.

## Дизайн
- Почти чёрный `#0b1016` + **один акцент «вольт» `#d8f24a`** только на логотипе и активном номере в индексе справа.
  Автор: «сдержанность — то, что не даёт тёмной фото-странице выглядеть как дашборд».
- Шрифты: **Anybody** (широкий гротеск с осью ширины, `wdth 125`) + **Manrope**.
  Оригинальные шрифты платные (PP Monument Extended, Quatro) и заменены бесплатными с похожим характером.
  Правило: широкий шрифт нужен **настоящий широкий**, растянуть обычный разрядкой нельзя.
- Капс-метки 11 px с разрядкой 0.06em.
- «Стекло»: полупрозрачный градиент + рамка 26% белого + внутренний блик сверху + размытие 18 px.
- Карточки со скруглением 46 px, тонкая рамка 28% белого.
- Числа в карточке **считаются от 0** вместе со скроллом (85%, 92 км, 74 км/ч, 45 мин) + полоска-шкала с подсветкой.
- Номерной индекс 01–05 справа, активный номер подсвечен акцентом.

## Подвал (обычная вёрстка, не холст)
Плашка со скруглением 28 px: призыв «Take the helm, *your way*» (курсив тоньше и тусклее), подписка, разделитель,
колонки ссылок, юридическая строка и **огромное название бренда, растворяющееся книзу** (градиент в тексте).

## Правила работы с промптом (тоже урок)
- Ассеты скачать и положить в проект, **ссылку на архив в коде не оставлять**: «чужое хранилище, а платят за трафик чужие».
- Не «улучшать» числа: они измерены, а не придуманы. Комментарии в коде объясняют, откуда цифры, и тоже часть проекта.
- Удалить мусор, который создаёт шаблон Vite.
- Проверка: `npm run lint` и `npm run build` без ошибок, изменить ширину окна — нет полос и обрезки.

## Что берём в агента
1. **Метод «таймлайн в мс → доли скролла»** (вписать в SKILL.md, этап «Код»). Сценарий пишем как раскадровку.
2. Функции `span` / `ramp` / `lerp` как базовый набор.
3. Каскад появления 0 / 75 / 150 мс для слов заголовка и 200 / 275 / 350 мс для строк текста.
4. Своё затемнение под каждый блок текста + маска для размытия шапки.
5. Числа, которые считаются от нуля.
6. Подбор бесплатной замены платному шрифту по характеру, а не по названию.

## Слабые места оригинала
- Кнопки «Reserve now / Watch demo» и «Login» — просто надписи, не ссылки.
- Подписка без отправки и без галочки согласия (152-ФЗ!).
- Нет мобильной раскладки холста: на телефоне весь холст уменьшается целиком, текст становится мелким.
  Для клиента нужен отдельный мобильный холст или обычная вёрстка ниже ~768 px.
