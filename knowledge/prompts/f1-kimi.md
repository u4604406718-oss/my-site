# Сайт гонщика F1: подробный разбор

PDF «f1», 27 страниц. Видео IMG_8364. Приёмы: 8 (стопка секций), 11 (курсор проявляет слой), 9 (прелоадер),
+ новые: **шахматное растворение на стыке блоков**, **линия, которая проезжает трассу**, **таймлайн с нитью-прогрессом**.

⚠️ Сайт сделан про **реального человека и реальный бренд** (Кими Антонелли, Mercedes-AMG). Для портфолио и продажи так нельзя.
Берём только приёмы.

## Суть
Светлый «спортивный журнал»: почти белый фон `#f7fafb`, чёрный текст, **один бирюзовый акцент `#02d2e3`**,
тёмные панели появляются по блокам. Пять блоков, первые три — **стопка**: блок прилипает, следующий наезжает поверх,
нижний уменьшается до 0.9 и темнеет до 55%.
1. **Герой:** фото гонщика с эффектом глубины, на нём шлем. После загрузки шлем **сгорает** бирюзовым фронтом,
   а потом виден **только там, где только что прошёл курсор** (жидкий след). Волна каркаса пробегает по невидимому шлему раз в 3.1 с.
2. **Сезон:** стык со светлым блоком — **шахматный флаг, который рассыпается** при прокрутке. Карта трассы из 8000 точек;
   при появлении бирюзовая линия **проезжает круг за 6 секунд**, тормозя в поворотах и разгоняясь на прямых. Потом курсор — прицел.
3. **Таймлайн «от картинга до F1»:** 7 фото в рамках со срезанными углами, нить-прогресс по центру и квадрат, который делает 5 оборотов.
4. **Паддок:** отчёт о гонке, полоса календаря.
5. **Подвал:** фигура гонщика «въезжает» на место, когда страница докручена до конца.

## Движок (общий для сайта)
- Один тикер `requestAnimationFrame` со счётчиком подписчиков; у каждого своя частота. **Lenis регистрируется первым**,
  чтобы все читали уже обновлённую прокрутку этого кадра.
- Всё, что двигается, — **пружины** (как в react-spring), шаг 1 мс, кадр не больше 64 мс. На странице нет ни одной CSS-анимации keyframes.
- **Три режима появления:**
  - `always` — показан, пока условие верно, иначе прячется;
  - `once` — один раз;
  - **`forward`** — играет при прокрутке вниз, а **при прокрутке вверх остаётся видимым** (не «моргает» обратно). Хороший стандарт.
- Текст: слова из `{прозрачность 0, сдвиг 0.35em}`, буквы из `0.3em`; **без обрезки по строке**, иначе срежутся хвосты букв
  при плотной высоте строки (0.95 / 0.72).
- Анимация считается только пока элемент на экране **плюс 10 кадров** после ухода.
- Пресеты пружин: REVEAL 90/26, ROW 170/24, SHEET 190/26, TYPE 210/24, VEIL 70/24, YEAR_SETTLE 32/26 и др.

## Стопка секций (как сделать правильно)
- Обёртка с тёмным фоном, слои `position: sticky; top: 0` с z-index 0 / 10, последний слой обычный (z 20) — возвращает нормальный поток.
- Внутри каждого слоя: обёртка, которую масштабируем, + тёмная «шторка» поверх (прозрачность от 0 до 0.55).
- **Трансформацию — только на внутреннюю обёртку**, не на sticky-элемент: иначе прилипание ломается.
- Ниже lg: `overflow-x: clip`, **не `hidden`** — `hidden` делает блок прокручиваемым и убивает прилипание.

## Прелоадер «силуэт продукта»
- Квадрат 7.2×8.5rem с маской в форме **силуэта шлема**: внутри заливка поднимается снизу (`scaleY` = прогресс).
  Под ним имя капсом с разрядкой 0.18em, внизу полоса 4 px.
- Прогресс **не измеряется**: медленно ползёт до 0.7 (мягкая пружина 10/30), а когда сцена готова — быстро до 1 (170/26).
- Выход в три такта: содержимое уходит вверх → через 670 мс гаснет фон → стартует вход страницы.
- Убирать экран только когда он **реально стал прозрачным**, а не по таймеру.
Этот прелоадер легко повторить с **силуэтом продукта клиента**: бутылка, чашка, кроссовок.

## Шахматное растворение (стык светлого и тёмного блока)
Полоса-холст высотой 34% экрана сверху тёмного блока: цвет светлого блока продолжается сплошными рядами,
потом распадается на шахматку и исчезает по мере прокрутки. Используется на трёх стыках (светлый → тёмный и наоборот).
Тематический переход (шахматный флаг = гонки). **Идея для агента:** стык блоков в стиле ниши — у пиццерии «крошки»,
у кофейни «капли», у ювелирки «блёстки».

## Линия по трассе
Путь трассы рисуется маской со штрихом (`stroke-dasharray` / `dashoffset`), скорость зависит от участка:
медленнее в поворотах, быстрее на прямых. На голове линии — белая «нить» и свечение. Отмечает 4 поворота по пути.
Фон: сетка пунктиром медленно «ползёт» (сдвиг штриха за 7 с), круги-«пинг» из центра раз в 4.2 с.
**Для агента:** так же можно «прорисовать» маршрут доставки, дорогу к дому, путь кофе от зерна до чашки.

## Таймлайн
- Фото 7 штук без промежутков: центральные (462 px высотой) и боковые (217), чередуются.
- По центру рельс: сплошная линия, потом пунктир; белая нить растёт с прокруткой; квадрат делает 5 оборотов
  и **останавливается на последней записи**, а не внизу блока.
- В каждой строке **три слоя параллакса**: рамка (боковые ±60, центральные ±20), фото внутри (−10% → 0), текст (±110) —
  ближний слой двигается сильнее. Двигают через `top`, не `transform`.
- Год собирается по буквам (шаг 26 мс), через 2.2 с на центральных строках гаснет до 40%.
- **Наведение на одно фото приглушает остальные до 30%.** Рамка с заливкой «сжимается» на 5% внутрь при наведении.
**Для агента:** это готовый блок «история бренда / этапы работы / путь клиента».

## Адаптив
- Размер шрифта «полосами»: 1 rem = 1 пиксель макета нужной ширины; ниже 1280 — фиксированные 16 px и раскладка по брейкпоинтам.
- Нижние блоки меряются в `cqw` (единицах ширины контейнера), поэтому совпадают с макетом на любой ширине.
- Отдельный брейкпоинт для **телефона горизонтально** (`max-height: 500px`).
- На сенсорных экранах курсор «стоит» в фиксированной точке, эффекты курсора отключены, плотность пикселей 1.
- `history.scrollRestoration = "manual"` + прокрутка наверх: страница всегда открывается с начала (из-за прелоадера).
